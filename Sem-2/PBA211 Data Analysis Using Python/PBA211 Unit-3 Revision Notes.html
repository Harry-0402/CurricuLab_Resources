Unit 3: Numerical Python (NumPy) & Pandas

Unit Overview

NumPy and Pandas are the two most important Python libraries for data analysis. NumPy provides powerful support for numerical computations through arrays, while Pandas offers data structures such as Series and DataFrames for data manipulation and analysis. This unit covers NumPy arrays, broadcasting, universal functions (U-Functions), Pandas basics, and working with live website data.

Key Concepts

NumPy (Numerical Python)

Definition

NumPy is a Python library used for numerical computing and efficient handling of large datasets.

Advantages

  • Faster than Python lists.
  • Supports multidimensional arrays.
  • Efficient memory usage.
  • Provides mathematical functions.

Importing NumPy

import numpy as np

NumPy Arrays

Definition

An array is a collection of elements of the same data type stored in contiguous memory locations.

Creating Arrays

import numpy as np

arr = np.array([10,20,30,40])
print(arr)

Output

[10 20 30 40]

Types of Arrays

One-Dimensional Array

arr = np.array([1,2,3,4])

Two-Dimensional Array

arr = np.array([
[1,2],
[3,4]
])

Three-Dimensional Array

arr = np.array([
[[1,2],[3,4]]
])

Array Attributes

Attribute Purpose
ndim Number of dimensions
shape Size of array
size Total elements
dtype Data type

Example

arr = np.array([1,2,3])

print(arr.ndim)
print(arr.shape)

Array Operations

Arithmetic Operations

a = np.array([1,2,3])
b = np.array([4,5,6])

print(a+b)

Output:

[5 7 9]

Multiplication

print(a*b)

Output:

[ 4 10 18]

Broadcasting

Definition

Broadcasting allows NumPy to perform operations between arrays of different sizes.

Example

arr = np.array([1,2,3])

print(arr + 10)

Output

[11 12 13]

Advantages

  • Faster calculations.
  • Reduces loops.
  • Improves performance.

Broadcasting Example

matrix = np.array([
[1,2,3],
[4,5,6]
])

print(matrix + 5)

Output

[[ 6  7  8]
 [ 9 10 11]]

Universal Functions (U-Functions)

Definition

U-Functions are vectorized functions that operate element-wise on NumPy arrays.

Benefits

  • High performance.
  • Faster execution.
  • Simplified code.

Common U-Functions

Addition

np.add([1,2],[3,4])

Output

[4 6]

Square Root

np.sqrt([4,9,16])

Output

[2. 3. 4.]

Maximum Value

np.max([10,20,50,15])

Output

50

Mean

np.mean([10,20,30])

Output

20

Introduction to Pandas

Definition

Pandas is a Python library used for data manipulation, cleaning, and analysis.

Advantages

  • Easy data handling.
  • Supports CSV and Excel files.
  • Powerful filtering and grouping.
  • Ideal for business analytics.

Importing Pandas

import pandas as pd

Series

Definition

A Series is a one-dimensional labeled array.

Creating a Series

import pandas as pd

data = pd.Series([10,20,30,40])

print(data)

Output

0    10
1    20
2    30
3    40

Characteristics

  • One-dimensional.
  • Has index labels.
  • Can store mixed data types.

DataFrame

Definition

A DataFrame is a two-dimensional tabular structure consisting of rows and columns.

Example

data = {
"Name":["Rahul","Priya"],
"Age":[21,22]
}

df = pd.DataFrame(data)

print(df)

Output

Name Age
Rahul 21
Priya 22

Why DataFrame?

  • Similar to Excel spreadsheets.
  • Supports large datasets.
  • Easy filtering and analysis.

Panel

Definition

A Panel is a three-dimensional data structure in Pandas.

Structure

Items
↓
Rows
↓
Columns

Note

Panel has largely been deprecated in modern Pandas versions but remains part of many academic syllabi.

Reading Data with Pandas

Read CSV File

df = pd.read_csv("sales.csv")

Display First Records

df.head()

Display Last Records

df.tail()

Data Inspection Functions

Function Purpose
head() First rows
tail() Last rows
info() Dataset summary
describe() Statistical summary
shape Number of rows & columns

Example

df.info()

Shows:

  • Column names
  • Data types
  • Missing values

Manipulating Live Data from Website

Definition

Data can be extracted directly from websites for analysis.

Methods

  1. Web Scraping
  2. API Access
  3. HTML Table Extraction

Reading HTML Tables

import pandas as pd

tables = pd.read_html("https://example.com")

Use

Extract tables from websites into DataFrames.

Frequently Asked Viva Questions

Why is NumPy faster than Python lists?

Because NumPy arrays are stored in contiguous memory and use optimized C implementations.

What is broadcasting?

A mechanism that allows arithmetic operations between arrays of different sizes.

Difference between Series and DataFrame?

  • Series → One-dimensional.
  • DataFrame → Two-dimensional.

What is the purpose of Pandas?

To clean, manipulate, analyze, and visualize structured data.

Unit 3 Summary

NumPy and Pandas are fundamental tools for data analysis in Python. NumPy provides efficient numerical computation through arrays, broadcasting, and U-Functions, while Pandas simplifies data manipulation using Series and DataFrames. Understanding these libraries is essential for performing real-world business and analytical tasks.
