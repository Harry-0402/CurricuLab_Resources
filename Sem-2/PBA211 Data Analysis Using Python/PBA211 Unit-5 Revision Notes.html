Unit 5: Data Extraction & Analysis

Unit Overview

Data Extraction and Analysis involve collecting data from different sources, processing it, and generating meaningful insights. Python provides powerful libraries such as Pandas, Requests, and Matplotlib to extract live data from APIs, visualize data, merge datasets, perform grouping operations, and analyze financial information. This unit focuses on practical data analytics techniques widely used in business and finance.

Key Concepts

Getting Live Data from APIs

Definition

API (Application Programming Interface) allows applications to communicate and exchange data over the internet.

Importance

  • Access real-time data.
  • Automate data collection.
  • Eliminate manual data entry.
  • Integrate multiple systems.

Examples

  • Weather Data API
  • Stock Market API
  • Currency Exchange API
  • Social Media API

Plot Data with Matplotlib

Definition

Matplotlib is a Python library used for creating graphs and charts.

Import

import matplotlib.pyplot as plt

Advantages

  • Easy visualization.
  • Supports multiple chart types.
  • Helps identify trends.
  • Widely used in analytics.

Line Chart

Example

import matplotlib.pyplot as plt

x = [1,2,3,4]
y = [10,20,30,40]

plt.plot(x,y)
plt.show()

Uses

  • Trend analysis
  • Sales growth analysis
  • Time-series data

Bar Chart

Example

products = ["A","B","C"]
sales = [100,200,150]

plt.bar(products,sales)
plt.show()

Uses

  • Product comparison
  • Performance analysis
  • Revenue comparison

Pie Chart

Example

sizes = [40,35,25]

plt.pie(sizes)
plt.show()

Uses

  • Market share
  • Budget allocation
  • Percentage contribution

Merge Data

Definition

Merging combines datasets based on common columns.

Example Tables

Customers

ID Name
1 Rahul
2 Priya

Orders

ID Amount
1 5000
2 7000

Merge Syntax

merged = pd.merge(
customers,
orders,
on="ID"
)

Output

ID Name Amount
1 Rahul 5000
2 Priya 7000

Types of Merge

Merge Type Description
Inner Join Common records only
Left Join All left table records
Right Join All right table records
Outer Join All records from both tables

Concatenate Data

Definition

Concatenation joins DataFrames either vertically or horizontally.

Example

combined = pd.concat(
[df1, df2]
)

Benefits

  • Combine datasets quickly.
  • Useful for monthly reports.
  • Easy data integration.

Merge vs Concatenate

Feature Merge Concatenate
Based on Key Yes No
Combines Related Data Yes No
Adds Rows/Columns Limited Yes

GroupBy in Pandas

Definition

GroupBy groups data based on categories and performs aggregate calculations.

Syntax

df.groupby("Column")

Example Dataset

Region Sales
North 1000
North 2000
South 1500

Calculate Total Sales by Region

df.groupby("Region")["Sales"].sum()

Output

Region Total Sales
North 3000
South 1500

Common GroupBy Functions

Function Purpose
sum() Total
mean() Average
max() Highest value
min() Lowest value
count() Count records

GroupBy Example

df.groupby(
"Department"
)["Salary"].mean()

Calculates average salary department-wise.

Important Definitions

  • API – Interface for exchanging data between applications.
  • JSON – Lightweight data format used by APIs.
  • Matplotlib – Python visualization library.
  • Merge – Combine datasets using common keys.
  • Concatenate – Join datasets together.
  • GroupBy – Group data and perform calculations.
  • Revenue – Total income generated.
  • Profit – Revenue minus Cost.

Frequently Asked Viva Questions

What is an API?

A mechanism that allows software applications to communicate and exchange data.

What is JSON?

A lightweight format used to store and exchange data.

Difference between Merge and Concatenate?

  • Merge combines data using common keys.
  • Concatenate joins DataFrames without keys.

Why is GroupBy important?

It helps summarize and analyze data category-wise.
