Unit 2: Advanced Python

Unit Overview

This unit introduces advanced Python programming concepts including functions, while loops, dictionaries, sets, slicing techniques, file handling, and CSV data analysis. These concepts are essential for building reusable programs and performing data analysis tasks efficiently.

Key Concepts

Creating Custom Functions

Definition

A function is a reusable block of code designed to perform a specific task.

Advantages

  • Reduces code repetition.
  • Improves readability.
  • Makes debugging easier.
  • Supports modular programming.

Syntax

def function_name():
    statements

Example

def greet():
    print("Welcome to Python")

greet()

Output

Welcome to Python

Functions with Parameters

Example

def add(a, b):
    return a + b

result = add(10, 20)
print(result)

Output

30

Types of Functions

Type Description
Built-in Functions Predefined functions like print(), len()
User-Defined Functions Created by programmers
Lambda Functions Anonymous single-line functions

Indefinite Loops (While Loops)

Definition

A while loop executes as long as a specified condition remains True.

Syntax

while condition:
    statements

Example

count = 1

while count <= 5:
    print(count)
    count += 1

Output

1
2
3
4
5

For Loop vs While Loop

Feature For Loop While Loop
Iterations Known Yes No
Condition Based No Yes
Usage Fixed repetitions Unknown repetitions

Dictionary Data Type

Definition

A Dictionary stores data as key-value pairs.

Syntax

student = {
    "name": "Rahul",
    "age": 21,
    "course": "MBA"
}

Characteristics

  • Mutable
  • Stores key-value pairs
  • Fast data retrieval
  • Keys must be unique

Accessing Values

print(student["name"])

Output

Rahul

Common Dictionary Operations

Add Item

student["city"] = "Nashik"

Update Item

student["age"] = 22

Delete Item

del student["city"]

Set Data Type

Definition

A Set is an unordered collection of unique elements.

Syntax

numbers = {1, 2, 3, 4}

Characteristics

  • No duplicate values.
  • Unordered.
  • Mutable.
  • Fast membership testing.

Example

numbers.add(5)

List vs Tuple vs Set

Feature List Tuple Set
Ordered Yes Yes No
Mutable Yes No Yes
Duplicates Allowed Yes Yes No
Brackets [] () {}

Slicing Data Types

Definition

Slicing extracts a portion of data from strings, lists, or tuples.

Syntax

sequence[start:end:step]

String Slicing

Example

name = "PYTHON"

print(name[0:3])

Output

PYT

List Slicing

Example

numbers = [10,20,30,40,50]

print(numbers[1:4])

Output

[20,30,40]

Negative Indexing

Example

name = "Python"

print(name[-1])

Output

n

Reading Text Files with Python

Definition

File handling allows reading and writing data stored in files.

Opening a File

file = open("data.txt","r")

Reading Entire File

content = file.read()
print(content)

Closing File

file.close()

Recommended Method

with open("data.txt","r") as file:
    content = file.read()
    print(content)

Advantage

Automatically closes the file.

Reading CSV Files

Definition

CSV (Comma Separated Values) files store tabular data.

Example CSV

Name,Age,City
Rahul,21,Nashik
Priya,22,Mumbai

Reading CSV Using Pandas

import pandas as pd

df = pd.read_csv("students.csv")

print(df)

Analyze Data from Text Files

Example

Suppose a file contains:

100
200
300
400

Program

with open("sales.txt","r") as file:
    total = 0

    for line in file:
        total += int(line)

print(total)

Output

1000

Analyze Data from CSV Files

Example

import pandas as pd

sales = pd.read_csv("sales.csv")

print(sales["Amount"].sum())

Purpose

Calculates total sales from CSV data.

Exception Handling (Important for File Operations)

Definition

Exception handling prevents programs from crashing due to errors.

Syntax

try:
    statements
except:
    error handling

Example

try:
    file = open("data.txt")
except:
    print("File not found")

Important Definitions

  • Function – Reusable block of code.
  • Parameter – Value passed into a function.
  • While Loop – Repeats while a condition is true.
  • Dictionary – Collection of key-value pairs.
  • Set – Collection of unique elements.
  • Slicing – Extracting part of a sequence.
  • Text File – File containing plain text.
  • CSV File – File storing tabular data.
