Unit V: Data Extraction & Analysis

Introduction

Data extraction and analysis are crucial stages in the data analytics lifecycle. Modern organizations collect data from multiple sources such as APIs, databases, websites, spreadsheets, and cloud platforms. After extracting data, analysts use Python libraries such as Pandas and Matplotlib to clean, analyze, and visualize information.

This unit covers API-based data extraction, data visualization using Matplotlib, merging and concatenating datasets, GroupBy operations, and financial what-if analysis using Pandas.

Topic 3: Merge and Concatenate Data

Explanation

Business data is often stored in multiple files or tables. Pandas provides methods to combine datasets.

A. Concatenation

Explanation

Concatenation joins datasets vertically or horizontally.

Example

import pandas as pd

df1 = pd.DataFrame({
    "A":[1,2]
})

df2 = pd.DataFrame({
    "A":[3,4]
})

result = pd.concat([df1,df2])

print(result)

Output:

0    1
1    2
0    3
1    4

B. Merge

Explanation

Merge combines datasets using common columns.

Example

df1 = pd.DataFrame({
    "ID":[1,2],
    "Name":["Amit","Rahul"]
})

df2 = pd.DataFrame({
    "ID":[1,2],
    "Salary":[50000,60000]
})

result = pd.merge(
    df1,
    df2,
    on="ID"
)

print(result)

Output:

ID   Name   Salary
1    Amit   50000
2    Rahul  60000

Types of Merge

Inner Join

Returns matching records.

Left Join

Returns all records from left table.

Right Join

Returns all records from right table.

Outer Join

Returns all records from both tables.

Combining customer information and transaction records.

Topic 4: GroupBy in Pandas

Explanation

GroupBy is one of the most powerful operations in Pandas.

It groups data based on one or more columns and performs aggregate operations.

Syntax

df.groupby("column")

Example Dataset

Department Salary
HR 50000
IT 70000
HR 60000
IT 80000

GroupBy Example

df.groupby(
    "Department"
)["Salary"].sum()

Output:

Department
HR    110000
IT    150000

Common Aggregation Functions

Sum

df.groupby(
    "Department"
).sum()

Mean

df.groupby(
    "Department"
).mean()

Maximum

df.groupby(
    "Department"
).max()

Minimum

df.groupby(
    "Department"
).min()

Applications

  • Department-wise salary analysis
  • Region-wise sales analysis
  • Product-wise revenue analysis

Topic 5: What-If Logic in Finance with Pandas

Explanation

What-If Analysis is a technique used to evaluate how changes in variables affect outcomes.

It is widely used in:

  • Finance
  • Budgeting
  • Forecasting
  • Risk analysis

Purpose

  • Scenario analysis
  • Financial planning
  • Decision-making
  • Sensitivity analysis

Example Scenario

A company wants to determine how profits change if sales increase by 10%.

Current Data

Sales Profit
100000 20000

Pandas Calculation

import pandas as pd

df = pd.DataFrame({
    "Sales":[100000],
    "Profit":[20000]
})

df["New Sales"] = (
    df["Sales"] * 1.10
)

print(df)

Output:

Sales    Profit   New Sales
100000   20000    110000

Multiple Scenarios

scenarios = [0.05,0.10,0.15]

for s in scenarios:
    print(
      df["Sales"] * (1+s)
    )
