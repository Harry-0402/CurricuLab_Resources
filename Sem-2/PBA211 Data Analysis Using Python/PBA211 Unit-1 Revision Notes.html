Unit 1: Introduction to Python

Unit Overview

Python is a high-level, interpreted, and easy-to-learn programming language widely used in data analysis, machine learning, web development, and automation. This unit introduces Python fundamentals including variables, data types, loops, conditional statements, tuples, and a practical mortgage calculator application.

Key Concepts

Variables

Definition

A variable is a named memory location used to store data values.

Syntax

name = "John"
age = 21

Key Points

  • Stores data temporarily.
  • Variable names are case-sensitive.
  • Cannot start with a number.
  • Improves code readability.

Example

student_name = "Rahul"
marks = 85

Numeric Data Types

Integer (int)

Definition

Stores whole numbers without decimal points.

Example

age = 20

Values

  • Positive: 10
  • Negative: -15
  • Zero: 0

Float

Definition

Stores numbers containing decimal points.

Example

salary = 25000.50

Key Points

  • Used for mathematical calculations.
  • Supports fractional values.

Integer vs Float

Sequential Data Types

String (str)

Definition

A sequence of characters enclosed in quotes.

Example

city = "Mumbai"

Operations

name = "Python"

List

Definition

An ordered collection of multiple items.

Example

fruits = ["Apple", "Mango", "Orange"]

Characteristics

  • Ordered
  • Mutable (can be modified)
  • Allows duplicate values

Common Operations

fruits.append("Banana")
fruits.remove("Apple")

Definite Loops (For Loops)

Definition

A for loop executes a block of code a fixed number of times.

Syntax

for i in range(5):
    print(i)

Output

0
1
2
3
4

Key Points

  • Used when number of iterations is known.
  • Easy to read and implement.
  • Commonly used with lists and ranges.

Example

for fruit in fruits:
    print(fruit)

Definition

Conditional statements used to make decisions.

Flowchart

Condition
↓

Syntax

    print("Grade A")

    print("Grade C")

Tuples

Definition

A tuple is an ordered collection of items that cannot be modified after creation.

Syntax

student = ("Rahul", 21, "MBA")

Characteristics

  • Ordered
  • Immutable
  • Allows duplicates
  • Faster than lists

Example

colors = ("Red", "Blue", "Green")

Tuple vs List

Feature Tuple List
Mutable No Yes

Build Mortgage Calculator with Python

Definition

A Mortgage Calculator calculates monthly loan payments based on principal amount, interest rate, and loan duration.

Formula

Monthly Payment Formula

[ M = P \times \frac{r(1+r)^n}{(1+r)^n - 1} ]

Where:

Symbol Meaning
M Monthly Payment
P Loan Amount
r Monthly Interest Rate
n Number of Payments

Simple Python Example

principal = 100000
interest = 0.08 / 12
years = 15

payments = years * 12

monthly_payment = (
principal *
(interest * (1 + interest) ** payments)
/
((1 + interest) ** payments - 1)
)

print(monthly_payment)
