Topic 1: Variables

Explanation

A Variable is a named memory location used to store data values.

Variables allow programs to store information that can be used and modified during execution.

Syntax

variable_name = value

Example

name = "John"
age = 25
salary = 50000

Here:

  • name stores text
  • age stores an integer
  • salary stores a numeric value

Rules for Naming Variables

Allowed

totalMarks
salary1

Not Allowed

student-name
class

Characteristics of Variables

  • Case Sensitive
  • Dynamic Typing
  • Easy Assignment
  • Reusable

Example 1

A company stores monthly sales in a variable.

Example 2

A weather application stores temperature readings.

Topic 7: Build Mortgage Calculator with Python

Explanation

A Mortgage Calculator helps determine monthly loan payments based on:

  • Loan Amount
  • Interest Rate
  • Loan Duration

This is a practical business application of Python.

Formula

Monthly Payment depends on:

  • Principal Amount (P)
  • Monthly Interest Rate (r)
  • Number of Months (n)

Mortgage Formula

M = P × [r(1+r)n] / [(1+r)n − 1]

Where:

  • M = Monthly Payment
  • P = Principal Amount
  • r = Monthly Interest Rate
  • n = Number of Monthly Payments

Python Program

principal = float(input("Loan Amount: "))
rate = float(input("Annual Interest Rate: "))
years = int(input("Years: "))

monthly_rate = rate / 100 / 12
months = years * 12

mortgage = principal * (
    monthly_rate * (1 + monthly_rate) ** months
) / ((1 + monthly_rate) ** months - 1)

print("Monthly Payment =", round(mortgage, 2))

Example 1

Loan Amount = ₹10,00,000

Interest Rate = 8%

Years = 10

Output:

Monthly Payment = ₹12133.59

Example 2

Loan Amount = ₹20,00,000

Interest Rate = 7%

Years = 15

Output:

Monthly Payment ≈ ₹17976
