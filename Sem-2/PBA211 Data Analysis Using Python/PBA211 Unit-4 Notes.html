Unit IV: Data Manipulation

Introduction

In Data Analytics, collecting data is only the first step. Real-world datasets are often incomplete, inconsistent, duplicated, or poorly formatted. Before analysis can begin, data must be cleaned, transformed, filtered, and organized. This process is known as Data Manipulation.

Python's Pandas library provides powerful tools for manipulating datasets efficiently. This unit focuses on creating DataFrames, slicing and filtering data, lambda functions, conditional operations, and business data analysis using CSV files.

Topic 1: Five Ways to Create a DataFrame

Explanation

A DataFrame is the most important data structure in Pandas. It organizes data in rows and columns similar to Excel spreadsheets and database tables.

Method 1: From Dictionary

import pandas as pd

data = {
    "Name":["Amit","Rahul","Neha"],
    "Marks":[80,90,85]
}

df = pd.DataFrame(data)
print(df)

Output:

    Name  Marks
0   Amit     80
1  Rahul     90
2   Neha     85

Method 2: From List

data = [
    ["Amit",80],
    ["Rahul",90],
    ["Neha",85]
]

df = pd.DataFrame(data,
                  columns=["Name","Marks"])

Method 3: From NumPy Array

import numpy as np

arr = np.array([
    [1,2],
    [3,4]
])

df = pd.DataFrame(arr)

Method 4: From CSV File

df = pd.read_csv("sales.csv")

Method 5: From Excel File

df = pd.read_excel("sales.xlsx")

Example 1

A retail company imports sales data from CSV files.

Example 2

Topic 2: Slicing and Filtering DataFrame

Explanation

Slicing and filtering allow analysts to select specific rows and columns from large datasets.

Selecting Columns

df["Name"]

Output:

0    Amit
1    Rahul
2    Neha

Multiple Columns

df[["Name","Marks"]]

Row Selection Using iloc

df.iloc[0]

Output:

Name     Amit
Marks      80

Row Selection Using loc

df.loc[0]

Filtering Data

Example

df[df["Marks"] > 80]

Output:

    Name  Marks
1  Rahul     90
2   Neha     85

Multiple Conditions

df[
    (df["Marks"] > 80)
    &
    (df["Marks"] < 90)
]

Example 1

Selecting customers with purchases above ₹10,000.

Example 2

Selecting students scoring above 75%.

Topic 3: Lambda Functions

Explanation

A Lambda Function is an anonymous (unnamed) function used for short operations.

It is useful when simple functions are required temporarily.

Syntax

lambda arguments : expression

Example

square = lambda x : x*x

print(square(5))

Output:

25

Lambda with Multiple Arguments

add = lambda a,b : a+b

print(add(10,20))

Output:

30

Using Lambda in DataFrames

df["Bonus"] = df["Marks"].apply(
    lambda x : x + 5
)

Output:

Marks Bonus
80 85
90 95
85 90

Advantages

  • Short and concise
  • Improves readability
  • Useful with apply()

Example 1

Calculating employee bonuses.

Example 2

Applying discounts to product prices.

Topic 4: Run If and Else Scenarios

Explanation

Business analytics frequently requires conditional decision-making.

Pandas allows conditional logic through standard Python functions and lambda expressions.

Using If-Else

marks = 85

if marks >= 50:
    print("Pass")
else:
    print("Fail")

Output:

Pass

Using Lambda with If-Else

df["Result"] = df["Marks"].apply(
    lambda x:
    "Pass" if x >= 50
    else "Fail"
)

Output:

Marks Result
80 Pass
90 Pass
45 Fail

Multiple Conditions

df["Grade"] = df["Marks"].apply(
 lambda x:
 "A" if x>=90
 else "B" if x>=75
 else "C"
)

Example 1

Employee performance classification.

Example 2

Customer segmentation based on spending.

Topic 6: Analyze Business Data from CSV Files

Explanation

CSV files are the most common format used for business data.

Examples:

  • Customer data

Sample CSV File

df = pd.read_csv("sales.csv")

Total Sales

total = df["Sales"].sum()

print(total)

100000

Average Sales

average = df["Sales"].mean()

Output:

33333.33

Maximum Sales

highest = df["Sales"].max()

50000

Minimum Sales

lowest = df["Sales"].min()

Output:

20000

Visualization Preparation

df.groupby(
