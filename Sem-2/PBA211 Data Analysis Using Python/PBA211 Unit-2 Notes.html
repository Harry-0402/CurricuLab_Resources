Unit II: Advanced Python

Introduction

After learning the basics of Python, the next step is to explore advanced programming concepts that make Python more powerful and practical for data analysis. Advanced Python includes custom functions, while loops, dictionaries, sets, slicing techniques, and file handling. These concepts help analysts automate repetitive tasks, organize data efficiently, and process large datasets.

This unit also introduces reading text and CSV files, which is a crucial skill for Business Analytics because real-world data is often stored in files.

Topic 1: Creating Custom Functions

Explanation

A Function is a block of reusable code designed to perform a specific task.

Instead of writing the same code repeatedly, functions allow us to write it once and reuse it whenever needed.

Syntax

def function_name():
    statements

Example

def greet():
    print("Welcome to Python")
    
greet()

Output:

Welcome to Python

Function with Parameters

def add(a, b):
    return a + b

result = add(10, 20)
print(result)

Output:

30

Advantages of Functions

  • Code reusability
  • Better organization
  • Reduced errors
  • Easier maintenance

Example 1

A bank creates a function to calculate loan interest.

def interest(principal, rate):
    return principal * rate / 100

Example 2

A retailer creates a function to calculate discounts.

def discount(price, percent):
    return price * percent / 100

Topic 2: Indefinite Loops – While Loops

Explanation

A While Loop executes repeatedly as long as a specified condition remains true.

Unlike a for loop, the number of iterations is not known beforehand.

Syntax

while condition:
    statements

Example

count = 1

while count <= 5:
    print(count)
    count += 1

Output:

1
2
3
4
5

Infinite Loop

If the condition never becomes false, the loop runs forever.

Example:

while True:
    print("Hello")

While Loop with User Input

password = ""

while password != "python":
    password = input("Enter Password: ")

print("Access Granted")

For Loop vs While Loop

Feature For Loop While Loop
Iterations Known Unknown
Control Automatic Manual
Use Case Fixed Repetition Condition-Based Repetition

Example 1

ATM machine keeps asking for PIN until correct PIN is entered.

Example 2

Online login system repeatedly asks for credentials.

Topic 3: Data Types – Dictionary and Set

A. Dictionary

Explanation

A Dictionary stores data in key-value pairs.

It is one of the most powerful Python data structures.

Syntax

dictionary = {
    key:value
}

Example

student = {
    "Name":"Rahul",
    "Age":22,
    "Marks":85
}

Accessing Values

print(student["Name"])

Output:

Rahul

Adding Data

student["City"] = "Mumbai"

Advantages

  • Fast retrieval
  • Organized storage
  • Flexible structure

Example 1

Customer database.

customer = {
    "ID":101,
    "Name":"Amit"
}

Example 2

Employee records.

employee = {
    "EmpID":5001,
    "Salary":45000
}

B. Set

Explanation

A Set is an unordered collection of unique values.

Duplicate values are automatically removed.

Example

numbers = {1,2,3,4,4,5}
print(numbers)

Output:

{1,2,3,4,5}

Set Operations

Add Element

numbers.add(6)

Remove Element

numbers.remove(2)

Applications

  • Removing duplicates
  • Membership testing
  • Mathematical operations

Example 1

Removing duplicate customer IDs.

Example 2

Finding unique products sold.

Topic 4: Slicing Data Types

Explanation

Slicing allows extraction of specific portions of data from strings, lists, and tuples.

Syntax

data[start:end]

String Slicing

text = "Python"

print(text[0:3])

Output:

Pyt

List Slicing

numbers = [10,20,30,40,50]

print(numbers[1:4])

Output:

[20,30,40]

Tuple Slicing

values = (1,2,3,4,5)

print(values[2:5])

Output:

(3,4,5)

Advantages

  • Quick extraction
  • Efficient processing
  • Reduced coding effort

Example 1

Extracting first three customer names.

Example 2

Selecting monthly sales data for a quarter.

Topic 5: Reading Text Files with Python

Explanation

Real-world data is often stored in text files. Python provides built-in functions to read and process file data.

Opening a File

file = open("sample.txt", "r")

Reading Entire File

file = open("sample.txt", "r")

content = file.read()

print(content)

file.close()

Reading Line by Line

file = open("sample.txt")

for line in file:
    print(line)

Using with Statement

with open("sample.txt","r") as file:
    content = file.read()

Automatically closes file.

Topic 6: Analyze Data from Text and CSV Files

Explanation

CSV (Comma-Separated Values) files are widely used in Business Analytics because they store structured data efficiently.

Reading CSV Files

import csv

with open("sales.csv") as file:
    reader = csv.reader(file)

    for row in reader:
        print(row)

Sample CSV Data

Name,Sales
Amit,5000
Rahul,7000
Neha,9000

Calculating Total Sales

import csv

total = 0

with open("sales.csv") as file:
    reader = csv.reader(file)

    next(reader)

    for row in reader:
        total += int(row[1])

print("Total Sales =", total)

Output:

Total Sales = 21000

Finding Maximum Sales

highest = 0

with open("sales.csv") as file:
    reader = csv.reader(file)

    next(reader)

    for row in reader:
        sale = int(row[1])

        if sale > highest:
            highest = sale

print(highest)

Output:

9000

Applications of CSV Analysis

  • Sales analysis
  • Customer analysis
  • Financial reporting
  • Inventory management

Example 1
