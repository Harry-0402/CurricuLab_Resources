Unit 4: Data Manipulation

Unit Overview

Data Manipulation is the process of organizing, cleaning, filtering, transforming, and analyzing data to extract meaningful information. In Pandas, DataFrames are the primary structures used for data manipulation. This unit covers DataFrame creation, slicing, filtering, lambda functions, conditional operations, and business data analysis using CSV files.

Key Concepts

Data Manipulation

Definition

Data Manipulation refers to modifying, organizing, cleaning, and transforming data to make it useful for analysis.

Objectives

  • Clean raw data.
  • Remove inconsistencies.
  • Extract useful information.
  • Prepare data for reporting.

Example

Removing duplicate customer records before analysis.

Five Ways to Create a DataFrame

1. From Dictionary

Example

import pandas as pd

data = {
    "Name":["Rahul","Priya"],
    "Age":[21,22]
}

df = pd.DataFrame(data)

Output

Name Age
Rahul 21
Priya 22

2. From List

data = [
    ["Rahul",21],
    ["Priya",22]
]

df = pd.DataFrame(data,
columns=["Name","Age"])

3. From NumPy Array

import numpy as np

arr = np.array([
    [1,2],
    [3,4]
])

df = pd.DataFrame(arr)

4. From CSV File

df = pd.read_csv("students.csv")

5. From Excel File

df = pd.read_excel("students.xlsx")

DataFrame Structure

Component Description
Rows Records

Slicing DataFrames

Definition

Slicing means selecting a subset of rows or columns.

Selecting Columns

df["Name"]

Selecting Multiple Columns

df[["Name","Age"]]

Row Slicing

Syntax

df[start:end]

Example

df[0:3]

Returns first three rows.

Using loc[]

Definition

Label-based selection.

Example

df.loc[0]

Returns first row.

Using iloc[]

Definition

Position-based selection.

Example

df.iloc[0]

Returns first row by index position.

Filtering DataFrames

Definition

Filtering selects rows based on conditions.

Example

df[df["Age"] > 21]

Output

Only records with Age greater than 21.

Multiple Conditions

Example

df[
(df["Age"] > 20)
&
(df["City"] == "Mumbai")
]

Lambda Functions

Definition

A Lambda Function is an anonymous single-line function.

Syntax

lambda arguments : expression

Example

square = lambda x : x*x

print(square(5))

Output

25

Lambda with DataFrame

Example

df["Bonus"] = df["Salary"].apply(
lambda x: x * 0.10
)

Result

Creates a Bonus column equal to 10% of Salary.

Run If and Else Scenarios

Using if-else

Example

sales = 5000

if sales > 3000:
    print("Target Achieved")
else:
    print("Target Not Achieved")

Using Lambda with If-Else

Example

df["Status"] = df["Sales"].apply(
lambda x:
"High"
if x > 5000
else "Low"
)

Frequently Asked Viva Questions

What is a DataFrame?

A two-dimensional table-like structure used in Pandas.

Difference between loc[] and iloc[]?

  • loc[] → Label-based indexing.
  • iloc[] → Position-based indexing.

Why use Lambda functions?

To create short and quick functions without defining them separately.

What is data cleaning?

The process of correcting or removing inaccurate and incomplete data.
