Unit III: Numerical Python & Pandas

Introduction

Data Analysis often involves working with large datasets and performing mathematical operations efficiently. Standard Python lists are useful, but they become slow when handling large-scale numerical computations. This is where NumPy and Pandas become important.

  • NumPy (Numerical Python) provides fast and efficient numerical computations.
  • Pandas provides powerful tools for data manipulation and analysis.

These libraries are widely used in Business Analytics, Data Science, Machine Learning, Financial Analysis, and Research.

Topic 1: NumPy Array

Explanation

NumPy (Numerical Python) is a Python library used for numerical computing.

The main object in NumPy is the Array (ndarray).

Unlike Python lists, NumPy arrays:

  • Consume less memory
  • Execute faster
  • Support mathematical operations directly

Importing NumPy

import numpy as np

Creating Arrays

One-Dimensional Array

import numpy as np

arr = np.array([10,20,30,40])

print(arr)

Output:

[10 20 30 40]

Two-Dimensional Array

arr = np.array([
    [1,2,3],
    [4,5,6]
])

print(arr)

Output:

[[1 2 3]
 [4 5 6]]

Array Properties

arr.shape

Output:

(2,3)

Meaning:

  • 2 rows
  • 3 columns

Advantages of NumPy Arrays

Feature Python List NumPy Array
Speed Moderate Fast
Memory Usage High Low
Mathematical Operations Limited Efficient
Scalability Lower Higher

Example 1

A financial analyst stores daily stock prices in a NumPy array.

Example 2

A retailer stores monthly sales data for analysis.

Topic 2: Broadcasting and U-Functions

Explanation

NumPy allows mathematical operations on arrays without using loops.

This feature is called Broadcasting.

Broadcasting

Example

import numpy as np

arr = np.array([1,2,3])

result = arr + 10

print(result)

Output:

[11 12 13]

The value 10 is automatically added to every element.

Multiplication Example

arr = np.array([10,20,30])

print(arr * 2)

Output:

[20 40 60]

Universal Functions (U-Functions)

Explanation

Universal Functions are built-in NumPy functions that operate element-wise.

Square Root

np.sqrt([4,9,16])

Output:

[2. 3. 4.]

Exponential Function

np.exp([1,2,3])

Trigonometric Function

np.sin([0,1,2])

Example 1

A bank applies interest calculations across multiple accounts simultaneously.

Example 2

A manufacturing company performs batch calculations on production data.

Topic 4: Series

Explanation

A Series is a one-dimensional labeled array capable of storing different data types.

Creating a Series

import pandas as pd

sales = pd.Series([1000,2000,3000])

print(sales)

Output:

0    1000
1    2000
2    3000
dtype: int64

Custom Index

sales = pd.Series(
    [1000,2000,3000],
    index=["Jan","Feb","Mar"]
)

print(sales)

Output:

Jan    1000
Feb    2000
Mar    3000

Accessing Values

sales["Jan"]

Output:

1000

Example 1

Monthly sales values.

Example 2

Student marks by roll number.

Topic 5: DataFrame

Explanation

A DataFrame is a two-dimensional table consisting of rows and columns.

It is the most widely used Pandas structure.

Creating a DataFrame

import pandas as pd

data = {
    "Name":["Amit","Rahul","Neha"],
    "Marks":[80,90,85]
}

df = pd.DataFrame(data)

print(df)

Output:

    Name  Marks
0   Amit     80
1  Rahul     90
2   Neha     85

Selecting Columns

df["Name"]

Selecting Rows

df.iloc[0]

DataFrame Operations

View First Rows

df.head()

Summary Information

df.info()

Statistical Summary

df.describe()

Example 1

A company stores employee records in a DataFrame.

Example 2

A university stores student results in a DataFrame.

Topic 7: Manipulate Live Data from Website

Explanation

Business analysts often collect live data from websites for analysis.

Pandas can directly read data from online sources.

Reading Data from Website

import pandas as pd

url = "https://example.com/data.csv"

df = pd.read_csv(url)

print(df.head())

Reading HTML Tables

tables = pd.read_html(
    "https://example.com"
)
