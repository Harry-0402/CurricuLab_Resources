Unit 5: Quality Management and Lean Production Systems

Unit Overview

Quality is a critical factor for customer satisfaction and business success. Organizations use inspection techniques, Statistical Quality Control (SQC), Six Sigma, Lean Production Systems, Toyota Production System (TPS), Just-In-Time (JIT), Kanban, and Theory of Constraints (TOC) to improve quality, reduce waste, and increase productivity. This unit also includes control chart numericals frequently asked in examinations.

Key Concepts

1. Inspection

Definition

Inspection is the process of checking products or services to ensure they meet specified standards and requirements.

Objectives

  • Detect defects.
  • Maintain quality standards.
  • Reduce customer complaints.
  • Ensure product reliability.
  • Improve customer satisfaction.

Types of Inspection

Type Description
Incoming Inspection Raw materials inspection
In-Process Inspection During production
Final Inspection Before delivery

2. 100% Inspection

Definition

Every item produced is inspected.

Advantages

  • Detects all defective items.
  • High quality assurance.
  • Suitable for critical products.

Disadvantages

  • Expensive.
  • Time-consuming.
  • Human errors possible.

Examples

  • Aircraft components.
  • Medical devices.
  • Nuclear equipment.

3. Sample Inspection

Definition

Only a selected sample from a lot is inspected.

Advantages

  • Lower cost.
  • Faster inspection.
  • Practical for large lots.

Disadvantages

  • Some defects may remain undetected.
  • Sampling risk exists.

Examples

  • Food products.
  • Consumer goods.
  • Textile industries.

Comparison: 100% vs Sample Inspection

Feature 100% Inspection Sample Inspection
Cost High Low
Time High Low
Accuracy Very High Moderate
Suitability Critical Products Mass Production

4. Operating Characteristic (OC) Curve

Definition

An OC Curve shows the probability of accepting a lot for different quality levels.

Purpose

  • Evaluates sampling plans.
  • Measures inspection effectiveness.
  • Balances producer and consumer risks.

Key Terms

Producer's Risk (α)

Good quality lot rejected.

Consumer's Risk (β)

Poor quality lot accepted.

Interpretation

  • Steeper OC Curve = Better discrimination.
  • Flatter OC Curve = Less accurate sampling plan.

6. Control Charts

Definition

Control Charts are graphical tools used to monitor process variation over time.

Components

Component Meaning
UCL Upper Control Limit
CL Central Line
LCL Lower Control Limit

Interpretation

  • Points within limits → Process in control.
  • Points outside limits → Process out of control.

Variables Control Charts

Used when measurements are numerical.

7. X̄ (Mean) Chart

Purpose

Monitors process average.

Formula

[ UCL = \bar{X} + A_2\bar{R} ]

[ CL = \bar{X} ]

[ LCL = \bar{X} - A_2\bar{R} ]

Example

Used to monitor bottle filling quantity.

8. R Chart

Purpose

Monitors process variability.

Formula

[ UCL = D_4\bar{R} ]

[ CL = \bar{R} ]

[ LCL = D_3\bar{R} ]

Example

Monitoring variation in product dimensions.

Attribute Control Charts

Used when data is counted rather than measured.

9. p Chart

Purpose

Monitors proportion of defective items.

Formula

[ p = \frac{\text{Defectives}}{\text{Sample Size}} ]

[ UCL = p + 3\sqrt{\frac{p(1-p)}{n}} ]

[ LCL = p - 3\sqrt{\frac{p(1-p)}{n}} ]

Example

Monitoring defective mobile phones.

10. np Chart

Purpose

Monitors number of defectives.

Formula

[ UCL = np + 3\sqrt{np(1-p)} ]

[ LCL = np - 3\sqrt{np(1-p)} ]

Example

Defective products in a fixed sample size.

11. c Chart

Purpose

Monitors number of defects per unit.

Formula

[ UCL = c + 3\sqrt{c} ]

[ LCL = c - 3\sqrt{c} ]

Example

Number of scratches on metal sheets.

12. n Chart

Purpose

Used for monitoring sample size variations.

Example

Quality inspection where sample size changes regularly.

Control Chart Summary

Chart Used For
X̄ Chart Process Average
R Chart Process Variation
p Chart Fraction Defective
np Chart Number Defective
c Chart Number of Defects
n Chart Sample Size Monitoring

Important Numerical Concept

Example (p Chart)

Defective items = 20

Sample Size = 200

[ p=\frac{20}{200}=0.10 ]

This value is used to calculate UCL and LCL.

Exam Tip: Remember chart formulas and identify whether data is measured (X̄, R) or counted (p, np, c).

13. Six Sigma

Definition

Six Sigma is a quality improvement methodology aimed at reducing defects and process variation.

Goal

Only 3.4 defects per million opportunities (DPMO).

DMAIC Methodology

Define
↓
Measure
↓
Analyze
↓
Improve
↓
Control

Benefits

  • Improved quality.
  • Reduced defects.
  • Lower costs.
  • Increased customer satisfaction.

Example

Reducing defects in smartphone manufacturing.

14. Lean Production System

Definition

Lean Production is a philosophy focused on eliminating waste while maximizing customer value.

Objectives

  • Reduce waste.
  • Improve efficiency.
  • Lower costs.
  • Increase customer value.

Seven Wastes (Muda)

Waste Meaning
Overproduction Producing more than needed
Waiting Idle time
Transportation Unnecessary movement
Overprocessing Extra work
Inventory Excess stock
Motion Unnecessary worker movement
Defects Rework and scrap

Benefits

  • Faster production.
  • Reduced inventory.
  • Improved quality.
  • Better productivity.

15. Toyota Production System (TPS)

Definition

Toyota Production System is a manufacturing philosophy developed by Toyota focusing on waste elimination and continuous improvement.

Pillars of TPS

Toyota Production System
↓
Just-In-Time (JIT)
+
Jidoka (Built-in Quality)

Principles

  • Continuous improvement (Kaizen).
  • Respect for people.
  • Waste elimination.
  • Quality at source.

Example

Toyota automobile production system.

16. Just-In-Time (JIT)

Definition

JIT is a production system where materials arrive exactly when needed.

Objectives

  • Reduce inventory.
  • Eliminate waste.
  • Improve cash flow.
  • Increase efficiency.

Process Flow

Supplier
↓
Production
↓
Customer

Advantages

  • Lower inventory cost.
  • Reduced storage requirements.
  • Improved quality.

Disadvantages

  • Supply disruptions affect production.
  • Requires accurate planning.

17. Kanban

Definition

Kanban is a visual scheduling system used to control material flow in JIT systems.

Meaning

Kanban = "Visual Signal" or "Card"

Process

Customer Demand
↓
Kanban Signal
↓
Production
↓
Replenishment

Benefits

  • Reduces inventory.
  • Improves workflow.
  • Enhances communication.
  • Prevents overproduction.

Example

Color-coded cards used in assembly lines.

18. Theory of Constraints (TOC)

Definition

TOC is a management philosophy developed by Eliyahu M. Goldratt that focuses on identifying and managing bottlenecks.

Core Idea

A system is only as strong as its weakest constraint.

Five Focusing Steps

Identify Constraint
↓
Exploit Constraint
↓
Subordinate Other Activities
↓
Elevate Constraint
↓
Repeat Process

Benefits

  • Improves throughput.
  • Reduces bottlenecks.
  • Enhances productivity.
  • Better resource utilization.

Example

Increasing capacity at the slowest machine in a production line.
