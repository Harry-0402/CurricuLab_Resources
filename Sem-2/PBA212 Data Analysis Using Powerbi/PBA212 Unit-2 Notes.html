Unit 2: Power Query

Introduction

In real-world business environments, data is collected from various sources such as Excel files, databases, websites, ERP systems, and cloud platforms. However, this data is often incomplete, inconsistent, or improperly formatted. Before analysis can begin, the data must be cleaned and transformed.

Power Query is a data preparation and transformation tool in Power BI that helps users connect to different data sources, clean data, transform it into a usable format, and load it into Power BI for analysis.

Power Query follows the principle:

Raw Data ↓ Data Cleaning ↓ Data Transformation ↓ Data Loading ↓ Analysis & Reporting

Topic 1: Data Transformation

Explanation

Data Transformation is the process of converting raw data into a structured and meaningful format suitable for analysis.

Raw data may contain:

  • Missing values
  • Duplicate records
  • Incorrect formats
  • Unwanted columns
  • Inconsistent entries

Power Query provides tools to solve these issues.

Common Data Transformation Activities

Activity Purpose
Cleaning Data Remove errors and duplicates
Filtering Data Keep only required records
Sorting Data Arrange data systematically
Splitting Columns Separate combined data
Merging Columns Combine multiple fields
Changing Data Types Convert data formats

Example 1

A company receives customer data where phone numbers contain extra spaces. Power Query removes unnecessary spaces.

Example 2

A student receives attendance data with duplicate entries and removes duplicates before analysis.

Topic 2: Benefits of Data Transformation

Explanation

Data transformation improves the quality and usability of data.

Benefits

  • Improves data accuracy.
  • Eliminates inconsistencies.
  • Saves time in analysis.
  • Enhances decision-making.
  • Creates standardized datasets.
  • Reduces reporting errors.

Before and After Transformation

Raw Data Transformed Data
Incomplete records Complete records
Duplicate rows Unique rows
Mixed formats Standardized formats
Unorganized data Structured data

Example 1

A bank standardizes customer account formats before generating reports.

Example 2

An online store converts different date formats into a single format.

Topic 3: Shape or Transform Data Using Power Query

Explanation

"Shaping Data" means modifying data to meet analytical requirements.

Users can:

  • Remove unwanted columns.
  • Rename columns.
  • Change data types.
  • Split and merge columns.
  • Filter records.
  • Rearrange data structure.

Data Shaping Process

Import Data ↓ Review Data ↓ Apply Transformations ↓ Validate Results ↓ Load Data

Example 1

A sales manager removes unnecessary supplier information before analysis.

Example 2

A school separates student full names into first and last names.

Topic 4: Overview of Power Query / Query Editor

Explanation

Query Editor is the working environment where data transformation operations are performed.

It allows users to:

  • View data
  • Modify data
  • Track transformation steps
  • Preview results before loading

Every transformation performed is recorded automatically.

Key Features

  • No coding required for basic operations.
  • Step-by-step transformation tracking.
  • Supports multiple data sources.
  • Reusable transformation processes.

Example 1

A finance analyst cleans accounting records using Query Editor.

Example 2

An HR executive transforms employee data before reporting.
