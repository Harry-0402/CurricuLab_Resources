Unit 2: Power Query

Unit Overview

Power Query is the data transformation and preparation engine in Power BI. It allows users to connect to multiple data sources, clean data, transform data, and prepare it for analysis. This unit focuses on Query Editor, data transformation techniques, filtering, column operations, and data reshaping tools such as Pivot and Unpivot.

Key Concepts

Data Transformation

Definition

Data Transformation is the process of converting raw data into a clean, structured, and usable format for analysis.

Key Points

  • Improves data quality.
  • Removes errors and inconsistencies.
  • Standardizes data formats.
  • Makes data analysis easier.

Example

Converting date formats from DD/MM/YYYY to MM/DD/YYYY.

Benefits of Data Transformation

Key Points

  • Improves accuracy of reports.
  • Removes duplicate records.
  • Enhances data consistency.
  • Saves analysis time.
  • Supports better decision-making.

Example

Cleaning customer records before creating sales reports.

Shape or Transform Data Using Power Query

Definition

Shaping data means modifying the structure, format, or content of data before loading it into Power BI.

Common Transformations

  • Remove unnecessary columns.
  • Rename columns.
  • Change data types.
  • Split or merge columns.
  • Filter records.
  • Pivot and Unpivot data.

Example

Splitting a "Full Name" column into First Name and Last Name.

Power Query / Query Editor Overview

Definition

Query Editor is the workspace used to clean and transform data before loading it into Power BI.

Functions

  • Data cleaning
  • Data transformation
  • Data shaping
  • Data preparation

Queries Pane

Definition

Displays all imported tables and queries.

Key Points

  • Helps manage multiple datasets.
  • Allows easy switching between queries.
  • Supports renaming queries.

Example

Sales, Customer, and Product tables shown as separate queries.

Data View / Results Pane

Definition

Displays preview of transformed data.

Key Points

  • Shows current data status.
  • Allows quick validation.
  • Reflects applied transformations.

Example

Viewing filtered customer records after applying a filter.

Query Settings Pane

Definition

Shows all transformation steps applied to data.

Key Points

  • Tracks every modification.
  • Allows editing of previous steps.
  • Helps in troubleshooting.

Example

Source → Changed Type → Filtered Rows → Renamed Columns.

Formula Bar

Definition

Displays Power Query M language expressions.

Key Points

  • Shows underlying transformation code.
  • Can be edited manually.
  • Supports advanced transformations.

Example

= Table.RemoveColumns(Source,{"Column1"})

Changing Data Types

Steps

  1. Select column.
  2. Choose Data Type.
  3. Select appropriate type.
  4. Confirm conversion.

Importance

  • Ensures accurate calculations.
  • Improves report performance.
  • Prevents data errors.

Filtering Data in Power Query

Auto Filter / Basic Filtering

Definition

Allows users to display only required records.

Example

Show only sales above ₹50,000.

Text Filters

Common Options

  • Equals
  • Does Not Equal
  • Begins With
  • Ends With
  • Contains

Example

Filter cities containing "Mumbai".

Number Filters

Common Options

  • Greater Than
  • Less Than
  • Between
  • Equals

Example

Display products costing more than ₹1,000.

Date Filters

Common Options

  • Before
  • After
  • Between
  • This Month
  • Last Year

Example

Show orders placed in 2024 only.

Filter Multiple Columns

Purpose

Apply conditions on more than one column simultaneously.

Example

Sales > ₹50,000 AND Region = West.

Column Operations

Remove Columns

Definition

Deletes unnecessary columns from a dataset.

Example

Removing internal employee IDs from customer reports.

Remove Other Columns

Definition

Keeps only selected columns and removes all others.

Example

Retaining Customer Name and Sales Amount only.

Name / Rename Column

Purpose

Makes column names meaningful and readable.

Example

Original Renamed
Cust_ID Customer ID
Amt Sales Amount

Reorder Columns

Definition

Changes the display sequence of columns.

Example

Customer Name before Customer ID.

Sort Columns

Types

  • Ascending (A-Z)
  • Descending (Z-A)

Example

Sort products by highest sales.

Add Column Operations

Add Column

Definition

Creates a new column from existing data.

Example

Profit = Sales − Cost.

Custom Column

Definition

Creates user-defined calculations.

Example

Commission = Sales × 5%

Split Columns

Definition

Divides one column into multiple columns.

Methods

  • By delimiter
  • By fixed number of characters

Example

Mumbai-Maharashtra → Mumbai | Maharashtra

Merge Columns

Definition

Combines multiple columns into a single column.

Example

First Name + Last Name
↓
Full Name

Pivot Columns

Definition

Converts row values into column headers.

Example

Product Sales
A 100
B 200

becomes

A B
100 200

Benefits

  • Better reporting.
  • Easy comparison.

Unpivot Columns

Definition

Converts columns into rows.

Example

Jan Feb
100 200

becomes

Month Sales
Jan 100
Feb 200

Benefits

  • Suitable for analysis.
  • Improves data modeling.

Transpose Columns

Definition

Converts rows into columns and columns into rows.

Example

A B
100 200

becomes

A 100
B 200

Important Definitions

  • Power Query – Tool used for data extraction and transformation.
  • Query Editor – Workspace for data cleaning and shaping.
  • Data Transformation – Converting raw data into usable format.
  • Pivot – Converting rows into columns.
  • Unpivot – Converting columns into rows.
  • Transpose – Swapping rows and columns.
  • Custom Column – User-created calculated column.
  • Filter – Selecting specific records.

Unit 2 Summary

Power Query is the backbone of data preparation in Power BI. It provides powerful tools for cleaning, transforming, filtering, reshaping, and preparing data before analysis.
