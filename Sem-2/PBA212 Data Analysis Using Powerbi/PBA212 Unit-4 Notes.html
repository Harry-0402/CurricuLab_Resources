Unit 4: DAX (Data Analysis Expressions)

Introduction

DAX (Data Analysis Expressions) is a formula language used in Power BI, Power Pivot, and Analysis Services. It helps users perform calculations, create custom measures, generate calculated columns, and build advanced business logic.

DAX enables analysts to go beyond simple reporting by creating dynamic calculations such as totals, averages, growth percentages, rankings, profit analysis, and time-based comparisons.

Importance of DAX

  • Performs advanced calculations.
  • Creates business metrics (KPIs).
  • Enhances reporting capabilities.
  • Supports dynamic analysis.
  • Improves decision-making.

DAX Workflow

Raw Data ↓ Data Model ↓ DAX Calculations ↓ Measures & Columns ↓ Reports & Dashboards

Topic 1: What is DAX?

Explanation

DAX stands for Data Analysis Expressions.

It is a collection of functions, operators, and constants used to create formulas in Power BI.

DAX is similar to Excel formulas but is much more powerful because it works across multiple related tables.

Uses of DAX

  • Calculate totals
  • Create percentages
  • Analyze trends
  • Generate KPIs
  • Create business metrics

Example 1

A company calculates total yearly revenue using DAX.

Example 2

A teacher calculates average marks of students using DAX.

Topic 2: Calculated Column

Explanation

A Calculated Column is a new column created using a DAX formula.

The value is calculated for every row and stored in the data model.

Characteristics

  • Calculated row by row.
  • Stored physically in the model.
  • Increases model size.
  • Useful for categorization.

Example

Sales Cost
5000 3000

Calculated Column:

Profit = Sales − Cost

Result:

Sales Cost Profit
5000 3000 2000

Example 1

Create Profit for every sales transaction.

Example 2

Create Age from Date of Birth.

Topic 3: Measures

Explanation

Measures are dynamic calculations performed at report runtime.

Unlike Calculated Columns, measures are not stored in the data model.

Characteristics

  • Calculated when needed.
  • Consumes less memory.
  • Suitable for aggregations.
  • Faster for large datasets.

Example

Total Sales = SUM(Sales[Amount])

Example 1

Calculate total company revenue.

Example 2

Calculate average student marks.

Topic 19: Filter Functions

Explanation

Filter functions manipulate calculation context and return filtered results.

Function Purpose
FILTER() Apply filter condition
ALL() Remove filters
RELATED() Access related table
VALUES() Unique values

Example

High Sales =
CALCULATE(
SUM(Sales[Amount]),
FILTER(Sales, Sales[Amount] > 10000)
)
