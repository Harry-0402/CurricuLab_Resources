Unit 5: Visualizations and Dashboards

Unit Overview

Visualizations are graphical representations of data that help users understand trends, patterns, comparisons, and insights quickly. Power BI provides a wide variety of charts and visual tools for effective data presentation. This unit covers different visualization types, their formatting, and dashboard creation, interaction, and sharing.

Key Concepts

Visualizing Data

Definition

Data Visualization is the graphical presentation of data using charts, graphs, maps, tables, and dashboards.

Key Points

  • Simplifies complex data.
  • Improves understanding.
  • Helps identify trends and patterns.
  • Supports data-driven decisions.

Example

Displaying monthly sales performance using a line chart.

Why Visualizations?

Benefits

  • Easy interpretation of large datasets.
  • Quick identification of trends.
  • Better business insights.
  • Improved communication.
  • Faster decision-making.

Example

Management can instantly identify declining sales regions through visual reports.

Bar and Column Charts

Bar Chart

Definition

Compares values across categories using horizontal bars.

Uses

  • Product comparison
  • Regional comparison
  • Performance analysis

Example

Product Sales
A 500
B 700
C 300

Displayed as horizontal bars.

Column Chart

Definition

Compares values using vertical columns.

Uses

  • Time-based comparisons
  • Category analysis
  • Revenue comparison

Example

Monthly sales comparison.

Stacked Charts

Stacked Bar Chart

Definition

Displays total values while showing contribution of different categories.

Example

Sales
↓
Product A
Product B
Product C

within the same bar.

Advantages

  • Shows composition and total value.
  • Easy category comparison.

Stacked Column Chart

Definition

Vertical version of the stacked bar chart.

Uses

  • Year-wise sales by region.
  • Product contribution analysis.

Clustered Charts

Clustered Bar Chart

Definition

Places multiple bars side by side for comparison.

Example

2023 Sales vs 2024 Sales

for each product.

Clustered Column Chart

Definition

Displays grouped vertical columns for comparison.

Advantages

  • Easy year-to-year comparison.
  • Clear category analysis.

100% Stacked Charts

100% Stacked Bar Chart

Definition

Shows percentage contribution rather than actual values.

Example

Region Percentage
North 40%
South 35%
West 25%

100% Stacked Column Chart

Purpose

Shows percentage distribution using vertical columns.

Use Case

Market share analysis.

Pie and Donut Charts

Pie Chart

Definition

Represents parts of a whole using slices.

Best Used For

  • Percentage contribution.
  • Market share analysis.
  • Budget distribution.

Example

Sales Contribution:

  • Product A = 40%
  • Product B = 35%
  • Product C = 25%

Donut Chart

Definition

A modified Pie Chart with a hole in the center.

Advantages

  • Cleaner appearance.
  • Better readability.
  • Space for additional labels.

Pie vs Donut Chart

Feature Pie Chart Donut Chart
Shape Full Circle Circle with Hole
Readability Moderate Better
Additional Information Limited Possible

Scatter Chart

Definition

Shows relationships between two numerical variables.

Components

  • X-axis
  • Y-axis
  • Data Points

Uses

  • Correlation analysis.
  • Performance comparison.
  • Trend identification.

Example

Advertising Spend vs Sales Revenue

Table Visual

Definition

Displays data in rows and columns.

Advantages

  • Detailed information.
  • Exact values.
  • Easy reporting.

Example

Product Quantity Sales
A 20 ₹10,000

Matrix Visualization

Definition

Advanced table visualization supporting hierarchies and aggregation.

Advantages

  • Drill-down analysis.
  • Summarized reporting.
  • Hierarchical views.

Example

Region
↓
State
↓
City

Line and Area Charts

Line Chart

Definition

Shows trends over time using connected data points.

Best Used For

  • Sales trends
  • Growth analysis
  • Forecasting

Example

Monthly Sales Trend

Jan → Feb → Mar → Apr

Area Chart

Definition

A line chart with the area below the line filled.

Advantages

  • Shows volume and trends.
  • Easy visualization of growth.

Stacked Area Chart

Definition

Displays multiple categories as stacked areas.

Uses

  • Contribution analysis.
  • Market trend comparisons.

Combo Charts

Definition

Combines multiple chart types into a single visual.

Advantages

  • Compare different measures.
  • Display trends and totals together.

Line and Stacked Column Chart

Example

Columns → Sales Revenue

Line → Profit Margin

Line and Clustered Column Chart

Example

Columns → Monthly Sales

Line → Growth Percentage

Ribbon Chart

Definition

Shows ranking changes over time.

Uses

  • Market share rankings.
  • Product performance rankings.
  • Competitive analysis.

Example

Top-selling products by month.

Waterfall Chart

Definition

Shows cumulative effects of positive and negative changes.

Example

Revenue
↓
Expenses
↓
Taxes
↓
Net Profit

Uses

  • Financial analysis.
  • Profitability analysis.
  • Budget tracking.

Funnel Chart

Definition

Displays stages in a process and shows drop-offs between stages.

Example

Leads
↓
Qualified Leads
↓
Opportunities
↓
Customers

Uses

  • Sales pipeline analysis.
  • Recruitment process tracking.
  • Marketing conversion analysis.

Creating Dashboards

Definition

A Dashboard is a single-page visual interface displaying important business metrics and insights.

Features

  • Interactive visuals.
  • Real-time monitoring.
  • Consolidated reporting.
  • Easy navigation.

Example

Executive Sales Dashboard displaying:

  • Revenue
  • Profit
  • Customers
  • Regional Performance

Advantages of Dashboards

Key Points

  • Quick decision-making.
  • Real-time business monitoring.
  • Improved productivity.
  • Better communication.
  • Centralized information.

Interacting with Dashboards

Common Interactions

Filtering

Select specific data.

Example: View only West Region sales.

Slicers

Interactive filters for users.

Example: Choose year, region, or product.

Drill-Down

Move from summary to detailed data.

Example:

Country
↓
State
↓
City

Cross-Filtering

Selecting one visual automatically filters others.

Unit 5 Summary

Visualizations are the core of Power BI reporting. Different chart types help present data effectively depending on the business requirement. Dashboards combine multiple visualizations into a single interactive view for monitoring and decision-making. Understanding chart selection, formatting, interactions, and sharing is essential for creating professional Power BI reports and dashboards.
