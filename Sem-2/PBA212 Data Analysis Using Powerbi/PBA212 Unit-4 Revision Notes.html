Unit 4: DAX (Data Analysis Expressions)

Unit Overview

DAX (Data Analysis Expressions) is the formula language used in Power BI for performing calculations, creating measures, calculated columns, and advanced data analysis. DAX helps users derive insights, perform aggregations, filter data, and create dynamic reports. This unit covers DAX basics, calculated columns, measures, operators, and important DAX functions.

Key Concepts

What is DAX?

Definition

DAX (Data Analysis Expressions) is a collection of functions, operators, and constants used to create formulas in Power BI.

Key Points

  • Used for data analysis and calculations.
  • Similar to Excel formulas.
  • Supports dynamic reporting.
  • Works with data models.

Example

Total Sales = SUM(Sales[Amount])

This formula calculates total sales.

Calculated Column

Definition

A Calculated Column is a new column created using a DAX formula.

Characteristics

  • Calculated row by row.
  • Stored in the data model.
  • Increases model size.
  • Computed during data refresh.

Example

Profit = Sales[Revenue] - Sales[Cost]

Output

Revenue Cost Profit
5000 3000 2000

Measures

Definition

A Measure is a dynamic calculation evaluated during report interaction.

Characteristics

  • Not physically stored.
  • Calculated when required.
  • Improves performance.
  • Used in visuals and dashboards.

Example

Total Revenue = SUM(Sales[Revenue])

Calculated Columns vs Measures

Feature Calculated Column Measure
Storage Stored in model Not stored
Calculation During refresh During report execution
Memory Usage High Low
Performance Slower Faster
Usage Row-level calculations Aggregated calculations

Exam Tip

Use Calculated Columns for row-wise computations and Measures for dynamic aggregations.

DAX Table and Column Name Syntax

Basic Syntax

TableName[ColumnName]

Example

Sales[Amount]

Rules

  • Table names come before column names.
  • Square brackets are mandatory for columns.
  • Names are case-insensitive.

DAX Syntax & Operators

Definition

Operators are symbols used to perform calculations and comparisons in DAX formulas.

Types of DAX Operators

1. Arithmetic Operators

Operator Meaning Example
+ Addition 5 + 3
- Subtraction 10 - 2
* Multiplication 5 * 4
/ Division 20 / 5
^ Power 2 ^ 3

Example

Profit = Revenue - Cost

2. Comparison Operators

Operator Meaning
= Equal To
<> Not Equal To
> Greater Than
< Less Than
>= Greater Than or Equal To
<= Less Than or Equal To

Example

Sales[Amount] > 10000

3. Text Concatenation Operator

Operator

&

Purpose

Combines text values.

Example

Full Name = Customer[First Name] & " " & Customer[Last Name]

Output:

John Smith

4. Logical Operators

Operator Meaning
&& AND
|| OR
NOT Negation

Example

Sales > 1000 && Region = "West"

DAX Functions

Definition

Functions are predefined formulas used to perform calculations and operations.

Types of DAX Functions

  1. Date and Time Functions
  2. Text Functions
  3. Logical Functions
  4. Math & Statistical Functions
  5. Filter Functions

Date and Time Functions

TODAY()

Purpose

Returns current date.

Example

TODAY()

Output:

10-Jan-2025 (example)

NOW()

Purpose

Returns current date and time.

Example

NOW()

YEAR()

Purpose

Extracts year from a date.

Example

YEAR(Sales[Order Date])

MONTH()

Purpose

Extracts month number.

Example

MONTH(Sales[Order Date])

Text Functions

LEN()

Purpose

Returns number of characters.

Example

LEN("Power BI")

Output:

8

LEFT()

Purpose

Returns characters from left side.

Example

LEFT("Power BI",5)

Output:

Power

RIGHT()

Purpose

Returns characters from right side.

Example

RIGHT("Power BI",2)

Output:

BI

UPPER()

Purpose

Converts text to uppercase.

Example

UPPER("power bi")

Output:

POWER BI

Logical Functions

IF()

Purpose

Performs conditional testing.

Syntax

IF(condition, true_result, false_result)

Example

IF(Sales[Amount] > 5000, "High", "Low")

AND()

Purpose

Checks multiple conditions.

Example

AND(Sales[Amount] > 1000, Sales[Amount] < 5000)

OR()

Purpose

Returns TRUE if any condition is true.

Example

OR(Sales[Amount] > 10000, Sales[Region]="West")

Math & Statistical Functions

SUM()

Purpose

Adds all values in a column.

Example

SUM(Sales[Amount])

AVERAGE()

Purpose

Calculates average value.

Example

AVERAGE(Sales[Amount])

MAX()

Purpose

Returns highest value.

Example

MAX(Sales[Amount])

MIN()

Purpose

Returns smallest value.

Example

MIN(Sales[Amount])

COUNT()

Purpose

Counts rows containing values.

Example

COUNT(Sales[Amount])

Filter Functions

CALCULATE()

Definition

Most powerful DAX function used to modify filter context.

Syntax

CALCULATE(Expression, Filter)

Example

West Sales =
CALCULATE(
SUM(Sales[Amount]),
Sales[Region]="West"
)

FILTER()

Purpose

Returns a filtered table.

Example

FILTER(Sales, Sales[Amount] > 1000)

ALL()

Purpose

Removes filters from a table or column.

Example

ALL(Sales)

Used for grand total calculations.

Important Definitions

  • DAX – Formula language used in Power BI.
  • Calculated Column – Row-by-row calculated field.
  • Measure – Dynamic calculation evaluated at runtime.
  • Operator – Symbol used in formulas.
  • Function – Predefined formula for calculations.
  • Filter Context – Data subset used in calculations.
  • CALCULATE() – Function that modifies filter context.
  • FILTER() – Function used to filter tables.
