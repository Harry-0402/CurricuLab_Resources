Unit 5: Analytical Techniques

Unit Overview

Analytical techniques are statistical methods used to analyze research data and make informed decisions. This unit covers parametric and non-parametric tests, ANOVA, correlation and regression, chi-square test, tests for normality, run test, and advanced techniques such as factor analysis, determinant analysis, and conjoint analysis.

Key Concepts

1. Parametric vs Non-Parametric Tests

Parametric Tests

Definition

Statistical tests that assume data follows a specific distribution (usually normal distribution).

Characteristics

  • Uses interval or ratio data.
  • Assumes normality.
  • More powerful when assumptions are satisfied.

Examples

  • Z-Test
  • t-Test
  • ANOVA
  • Pearson Correlation

Non-Parametric Tests

Definition

Statistical tests that do not require assumptions about population distribution.

Characteristics

  • Suitable for ordinal or nominal data.
  • Useful when normality assumptions are violated.
  • Simpler but generally less powerful.

Examples

  • Chi-square Test
  • Run Test
  • Sign Test
  • Mann-Whitney U Test

Parametric vs Non-Parametric

Feature Parametric Non-Parametric
Distribution Assumption Required Not Required
Data Type Interval/Ratio Nominal/Ordinal
Accuracy Higher Moderate
Complexity Higher Lower
Examples ANOVA, t-Test Chi-square, Run Test

2. ANOVA (Analysis of Variance)

Definition

ANOVA is a statistical technique used to compare the means of three or more groups.

Purpose

  • Determine whether significant differences exist among group means.
  • Reduce the need for multiple t-tests.

Hypotheses

Null Hypothesis (H₀)

All group means are equal.

Alternative Hypothesis (H₁)

At least one group mean differs.

ANOVA Procedure

State Hypotheses
↓
Calculate Variance
↓
Compute F-Ratio
↓
Compare with Critical Value
↓
Decision

F-Ratio Formula

[ F=\frac{\text{Variance Between Groups}}{\text{Variance Within Groups}} ]

Example

Comparing sales performance across three different sales regions.

3. Correlation

Definition

Correlation measures the strength and direction of the relationship between two variables.

Types of Correlation

Positive Correlation

Both variables move in the same direction.

Example: Income and spending.

Negative Correlation

Variables move in opposite directions.

Example: Price and demand.

Zero Correlation

No relationship exists.

Correlation Coefficient (r)

[ -1 \leq r \leq +1 ]

Value Interpretation
+1 Perfect Positive
0 No Correlation
-1 Perfect Negative

Example

Relationship between advertising expenditure and sales revenue.

4. Regression Analysis

Definition

Regression determines the impact of one variable on another and helps make predictions.

Purpose

  • Predict future outcomes.
  • Measure influence of independent variables.

Simple Regression Equation

[ Y = a + bX ]

Where:

  • Y = Dependent Variable
  • X = Independent Variable
  • a = Intercept
  • b = Regression Coefficient

Example

Predicting sales based on advertising expenditure.

Correlation vs Regression

Feature Correlation Regression
Purpose Measure relationship Predict relationship
Variable Dependency No distinction Independent & Dependent variables
Output Correlation Coefficient Regression Equation
Prediction Not Possible Possible

5. Chi-Square Test (χ²)

Definition

Chi-square is a non-parametric test used to examine relationships between categorical variables.

Applications

  • Test independence.
  • Test goodness of fit.
  • Analyze categorical data.

Formula

[ \chi^2=\sum \frac{(O-E)^2}{E} ]

Where:

  • O = Observed Frequency
  • E = Expected Frequency

Example

Determining whether gender influences product preference.

Conditions for Chi-Square Test

  • Data should be categorical.
  • Observations should be independent.
  • Expected frequencies should be adequate.

6. Non-Parametric Tests for Normality

Definition

These tests determine whether data follows a normal distribution.

Importance

  • Helps choose appropriate statistical tests.
  • Supports research validity.

Common Tests

  • Kolmogorov-Smirnov Test
  • Shapiro-Wilk Test

Interpretation

Result Meaning
Significant Data not normally distributed
Not Significant Data normally distributed

7. Run Test

Definition

Run Test is a non-parametric test used to determine randomness in a sequence of observations.

Purpose

  • Check randomness.
  • Detect patterns or trends.

Applications

  • Quality control.
  • Financial data analysis.
  • Market research.

Example

Testing whether customer arrivals occur randomly throughout the day.

8. Advanced Data Analysis Techniques

A. Factor Analysis

Definition

Factor Analysis is used to reduce a large number of variables into a smaller number of underlying factors.

Objectives

  • Data reduction.
  • Identify hidden dimensions.
  • Simplify analysis.

Example

Reducing 20 customer satisfaction variables into factors such as:

  • Service Quality
  • Price Perception
  • Brand Image

Factor Analysis Flowchart

Many Variables
↓
Identify Correlations
↓
Extract Factors
↓
Interpret Factors

B. Determinant Analysis

Definition

Determinant Analysis examines whether variables are sufficiently correlated for advanced statistical analysis.

Importance

  • Used before factor analysis.
  • Checks suitability of data matrix.
  • Helps identify multicollinearity issues.

Interpretation

  • Determinant close to 0 → High multicollinearity.
  • Larger determinant → Better suitability.

C. Conjoint Analysis

Definition

Conjoint Analysis is a technique used to determine how consumers value different attributes of a product or service.

Purpose

  • Understand customer preferences.
  • Support product design.
  • Assist pricing decisions.

Example

A smartphone buyer evaluates:

  • Price
  • Camera Quality
  • Battery Life
  • Storage Capacity

Conjoint analysis identifies which attribute is most important.

Important Definitions

  • Parametric Test – Statistical test based on distribution assumptions.
  • Non-Parametric Test – Statistical test without distribution assumptions.
  • ANOVA – Compares means of multiple groups.
  • Correlation – Measures strength and direction of relationship.
  • Regression – Predicts dependent variable using independent variable.
  • Chi-Square Test – Tests association between categorical variables.
  • Normality Test – Determines whether data follows normal distribution.
  • Run Test – Tests randomness of observations.
  • Factor Analysis – Reduces variables into factors.
  • Conjoint Analysis – Measures customer preference for product attributes.
