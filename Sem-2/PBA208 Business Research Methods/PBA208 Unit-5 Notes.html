Unit V: Analytical Techniques

Introduction

After collecting and analyzing data, researchers use various statistical techniques to test hypotheses, identify relationships, make predictions, and support business decisions. These techniques help transform raw data into meaningful insights.

Analytical techniques are broadly classified into Parametric Tests and Non-Parametric Tests. This unit covers ANOVA, Correlation and Regression, Chi-Square Test, Normality Tests, Run Test, and Advanced Data Analysis Techniques such as Factor Analysis, Determinant Analysis, and Conjoint Analysis.

Topic 1: Parametric vs Non-Parametric Tests

Explanation

Statistical tests are used to analyze data and test hypotheses.

Parametric Tests

Parametric tests assume that data follows a normal distribution and satisfies specific statistical assumptions.

Characteristics

  • Data is quantitative.
  • Population parameters are known or estimated.
  • Normally distributed data.
  • More powerful and accurate.

Examples

  • t-Test
  • ANOVA
  • Regression Analysis
  • Pearson Correlation

Non-Parametric Tests

Non-parametric tests do not require normal distribution assumptions.

Characteristics

  • Suitable for ordinal and nominal data.
  • Useful for small samples.
  • Flexible and easy to apply.

Examples

  • Chi-Square Test
  • Run Test
  • Mann-Whitney Test
  • Kruskal-Wallis Test

Comparison: Parametric vs Non-Parametric Tests

Feature Parametric Test Non-Parametric Test
Distribution Normal Distribution Required No Distribution Assumption
Data Type Interval/Ratio Nominal/Ordinal
Accuracy Higher Moderate
Sample Size Usually Larger Small or Large
Examples ANOVA, Regression Chi-Square, Run Test

Example 1

A company compares employee productivity using ANOVA.

Example 2

A retailer uses Chi-Square analysis to study customer preferences.

Topic 2: ANOVA (Analysis of Variance)

Explanation

ANOVA is a statistical technique used to compare the means of three or more groups.

It determines whether significant differences exist among group averages.

Purpose of ANOVA

  • Compare multiple groups.
  • Test hypotheses.
  • Reduce multiple t-tests.
  • Support business decisions.

Types of ANOVA

1. One-Way ANOVA

Compares groups based on one factor.

Example

Comparing sales performance across different regions.

2. Two-Way ANOVA

Compares groups using two factors.

Example

Comparing employee performance across departments and experience levels.

ANOVA Procedure

State Hypotheses
↓
Calculate Variance
↓
Compute F-Statistic
↓
Compare with Critical Value
↓
Decision

Hypotheses

H₀: All group means are equal.

H₁: At least one group mean differs.

Example 1

A company compares customer satisfaction levels across four branches.

Example 2

A university compares examination performance among different departments.

Topic 3: Correlation and Regression

A. Correlation Analysis

Explanation

Correlation measures the strength and direction of a relationship between two variables.

Types of Correlation

Positive Correlation

Both variables increase together.

Example:

Advertising ↑ → Sales ↑

Negative Correlation

One variable increases while the other decreases.

Example:

Price ↑ → Demand ↓

Zero Correlation

No relationship exists.

Correlation Coefficient

r = Σ(x − x̄)(y − ȳ) / √[Σ(x − x̄)² Σ(y − ȳ)²]

Range:

-1 ≤ r ≤ +1

Interpretation of Correlation

Value of r Interpretation
+1 Perfect Positive
0 No Correlation
-1 Perfect Negative

B. Regression Analysis

Explanation

Regression predicts the value of a dependent variable using one or more independent variables.

Uses

  • Forecasting
  • Prediction
  • Trend analysis
  • Decision-making

Simple Linear Regression

y = a + bx

Where:

  • y = Dependent Variable
  • x = Independent Variable
  • a = Intercept
  • b = Regression Coefficient

Example 1

Predicting sales using advertising expenditure.

Example 2

Predicting student performance using study hours.

Topic 4: Chi-Square Test

Explanation

The Chi-Square Test is a non-parametric test used to examine relationships between categorical variables.

Applications

  • Consumer preference analysis
  • Market research
  • Survey analysis
  • Demographic studies

Types of Chi-Square Tests

1. Test of Independence

Determines whether two variables are related.

Example

Gender and product preference.

2. Goodness of Fit Test

Determines whether observed data fits expected distribution.

Example

Customer preferences across product categories.

Chi-Square Formula

χ² = Σ (O − E)² / E

Where:

  • O = Observed Frequency
  • E = Expected Frequency

Example 1

A retailer examines whether gender influences purchasing decisions.

Example 2

A university studies the relationship between department and placement outcomes.

Topic 5: Non-Parametric Tests for Normality

Explanation

Before applying many statistical techniques, researchers need to determine whether data follows a normal distribution.

Normality tests help assess this requirement.

Importance

  • Selection of appropriate statistical methods.
  • Validation of assumptions.
  • Improved reliability of results.

Common Normality Tests

1. Shapiro-Wilk Test

Suitable for small samples.

2. Kolmogorov-Smirnov Test

Suitable for larger samples.

3. Anderson-Darling Test

Sensitive to deviations from normality.

Interpretation

If p-value > 0.05

Data is normally distributed.

If p-value < 0.05

Data is not normally distributed.

Example 1

A bank checks whether customer income data follows normal distribution.

Example 2

A researcher verifies normality before applying ANOVA.

Topic 6: Run Test

Explanation

Run Test is a non-parametric test used to determine whether observations occur randomly.

A "run" is a sequence of similar observations.

Purpose

  • Test randomness.
  • Detect patterns.
  • Evaluate independence.

Applications

  • Quality control
  • Stock market analysis
  • Survey data analysis

Run Test Procedure

Arrange Data
↓
Identify Runs
↓
Count Runs
↓
Calculate Test Statistic
↓
Decision

Example

Sequence:

H H H T T H T T

Runs:

(HHH) (TT) (H) (TT)

Total Runs = 4

Example 1

A manufacturing company checks whether defects occur randomly.

Example 2

A financial analyst studies stock market price movements.

Topic 7: Advanced Data Analysis Techniques

Explanation

Factor Analysis identifies underlying factors responsible for observed relationships among variables.

It reduces large datasets into smaller groups of related variables.

Objectives

  • Pattern identification
  • Simplification

Example

  • Product Quality
  • Pricing

B. Determinant Analysis

Explanation

Determinant Analysis examines factors influencing outcomes and helps identify important determinants of behavior or decisions.

Applications

C. Conjoint Analysis

Explanation

Conjoint Analysis is used to understand customer preferences regarding product features.

↓

↓
Analyze Preferences
↓
Determine Attribute Importance
