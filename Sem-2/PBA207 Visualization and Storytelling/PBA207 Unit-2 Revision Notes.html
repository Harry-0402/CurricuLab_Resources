Unit 2: Visualization of Structured Data

Unit Overview

Structured data is organized data stored in rows and columns, such as databases, spreadsheets, and data warehouses. Visualization of structured data helps analysts discover patterns, trends, and relationships through charts, dashboards, and reports. This unit covers exploratory analysis, univariate and multivariate analysis, visualization techniques, modeling, and deployment visualization.

Key Concepts

1. Introduction to Structured Data Visualization

Definition

Structured data visualization refers to presenting organized data graphically to improve understanding and decision-making.

Sources of Structured Data

  • Databases
  • Excel Sheets
  • ERP Systems
  • CRM Systems
  • Data Warehouses

Characteristics

  • Organized into rows and columns.
  • Easy to store and retrieve.
  • Suitable for statistical analysis.
  • Supports business intelligence tools.

Example

A company's sales database visualized through dashboards showing revenue, profit, and customer growth.

2. Exploratory Data Analysis (EDA)

Definition

Exploratory Data Analysis is the process of examining data before formal analysis to discover patterns, trends, and anomalies.

Objectives

  • Understand dataset characteristics.
  • Detect outliers.
  • Identify missing values.
  • Generate insights.

Key Activities

  • Data Cleaning
  • Data Summarization
  • Pattern Identification
  • Trend Analysis

EDA Process

Collect Data
↓
Clean Data
↓
Explore Variables
↓
Identify Patterns
↓
Generate Insights

Benefits

  • Improves data quality.
  • Supports better modeling.
  • Reduces analytical errors.

Example

Analyzing customer purchase data to identify high-value customers.

3. Univariate Analysis

Definition

Univariate analysis studies one variable at a time.

Purpose

  • Understand distribution.
  • Identify central tendency.
  • Detect variation.

Common Visualizations

Histogram

Shows frequency distribution.

Example: Distribution of student marks.

Box Plot

Displays spread and outliers.

Example: Salary distribution among employees.

Pie Chart

Shows percentage contribution.

Example: Market share by brand.

Bar Chart

Compares categorical values.

Example: Product sales comparison.

Measures Used

Measure Purpose
Mean Average value
Median Middle value
Mode Most frequent value
Range Spread of data
Standard Deviation Variability

4. Multivariate Analysis

Definition

Multivariate analysis examines multiple variables simultaneously.

Objectives

  • Discover relationships.
  • Identify influencing factors.
  • Improve predictions.

Common Visualizations

Scatter Plot Matrix

Shows relationships among variables.

Bubble Chart

Displays three variables simultaneously.

Heat Map

Represents values using color intensity.

Treemap

Visualizes hierarchical data.

Example

Analyzing customer satisfaction using:

  • Service Quality
  • Price
  • Product Availability
  • Brand Image

Univariate vs Multivariate Analysis

Feature Univariate Multivariate
Variables One Multiple
Complexity Low High
Purpose Description Relationship Analysis
Example Age Distribution Age, Income & Spending

5. Charts to Visualize Multiple Measures

Definition

Multiple-measure charts display more than one metric in a single visualization.

Importance

  • Compare metrics simultaneously.
  • Detect patterns quickly.
  • Improve dashboard efficiency.

Common Multi-Measure Charts

A. Combination Chart

Combines bar and line charts.

Example: Sales (bar) and Profit (line).

B. Dual Axis Chart

Uses two different scales.

Example: Revenue and Customer Count.

C. Bubble Chart

Displays:

  • X-axis variable
  • Y-axis variable
  • Bubble size variable

D. Heat Map

Shows relationships among multiple variables.

E. Radar Chart

Compares multiple dimensions.

Example: Employee performance across skills.

Multi-Measure Visualization Table

Chart Type Best Use
Combination Chart Compare trends and values
Bubble Chart Three-dimensional analysis
Heat Map Pattern identification
Radar Chart Multi-factor comparison
Dual Axis Chart Comparing different scales

6. Modeling

Definition

Modeling is the process of creating analytical or predictive models using data.

Purpose

  • Forecast future outcomes.
  • Identify key drivers.
  • Support business decisions.

Types of Models

Descriptive Models

Describe historical data.

Example: Sales performance reports.

Predictive Models

Predict future events.

Example: Customer churn prediction.

Prescriptive Models

Recommend actions.

Example: Inventory optimization.

Modeling Process

Data Collection
↓
Data Preparation
↓
Model Building
↓
Model Testing
↓
Model Deployment

Visualization in Modeling

Visualization helps:

  • Understand variables.
  • Evaluate model performance.
  • Identify trends and patterns.
  • Communicate model results.

Example

A regression line visualizing the relationship between advertising and sales.

7. Visualization During Deployment

Definition

Deployment visualization refers to monitoring and communicating model performance after implementation.

Objectives

  • Track KPIs.
  • Monitor business performance.
  • Detect issues early.
  • Support continuous improvement.

Common Deployment Visualizations

Dashboards

Real-time monitoring of KPIs.

Scorecards

Performance measurement reports.

KPI Visualizations

Track critical metrics.

Alert Systems

Highlight deviations from targets.

Important Definitions

  • Structured Data – Organized data stored in rows and columns.
  • Exploratory Data Analysis (EDA) – Initial examination of data.
  • Univariate Analysis – Analysis of one variable.
  • Multivariate Analysis – Analysis of multiple variables.
  • Modeling – Building analytical or predictive systems.
  • Dashboard – Visual interface displaying KPIs.
  • Heat Map – Color-coded representation of values.
  • Bubble Chart – Chart displaying three variables simultaneously.
  • Deployment – Implementation of a model in real-world use.
