Unit 4: PERT, CPM and Sequencing Problems

Introduction

Organizations frequently undertake projects such as construction, software development, product launches, infrastructure development, and research projects. Managing these projects effectively requires proper planning, scheduling, monitoring, and control.

PERT (Program Evaluation and Review Technique) and CPM (Critical Path Method) are project management tools that help managers estimate project completion time, identify critical activities, allocate resources efficiently, and control project progress.

In addition, organizations often face situations where multiple jobs must be processed on multiple machines. Sequencing Techniques help determine the optimal order of jobs to minimize total processing time and maximize efficiency.

This unit covers PERT, CPM, network diagrams, scheduling concepts, project completion probabilities, and sequencing problems.

Part A: PERT and CPM

Topic 1: Introduction to PERT and CPM

Explanation

PERT and CPM are network-based project management techniques used for planning, scheduling, and controlling projects.

PERT (Program Evaluation and Review Technique)

PERT is mainly used when activity times are uncertain.

Characteristics

  • Probabilistic approach.
  • Suitable for research and development projects.
  • Focuses on time estimation.

CPM (Critical Path Method)

CPM is used when activity times are known with certainty.

Characteristics

  • Deterministic approach.
  • Suitable for construction and manufacturing projects.
  • Focuses on cost and time optimization.

Comparison of PERT and CPM

Feature PERT CPM
Nature Probabilistic Deterministic
Time Estimates Three One
Focus Time Time and Cost
Suitable For R&D Projects Construction Projects

Topic 3: Earliest Start Time (EST)

Explanation

Earliest Start Time (EST) is the earliest time an activity can begin without violating project constraints.

It is calculated using a Forward Pass through the network.

Formula

ESTj = max(EFTi)

where all predecessor activities are considered.

Importance

  • Determines earliest project completion.
  • Helps schedule activities efficiently.

Example 1 (Business)

A construction project calculates EST to determine when foundation work can begin.

Example 2 (Practical)

A student identifies the earliest date to begin report writing after completing research.

Topic 4: Earliest Finish Time (EFT)

Explanation

Earliest Finish Time represents the earliest time an activity can be completed.

Formula

EFT = EST + Activity Duration

Importance

  • Supports project scheduling.
  • Helps estimate project duration.

Example 1 (Business)

A software development team calculates EFT for coding activities.

Example 2 (Practical)

A student estimates assignment completion dates.

Topic 5: Latest Start Time (LST)

Explanation

Latest Start Time is the latest an activity can start without delaying the project.

It is calculated using a Backward Pass.

Formula

LST = LFT - Activity Duration

Importance

  • Identifies scheduling flexibility.
  • Helps resource allocation.

Example 1 (Business)

A factory determines the latest start date for machine installation.

Example 2 (Practical)

An event organizer identifies the latest date for venue booking.

Topic 6: Latest Finish Time (LFT)

Explanation

Latest Finish Time is the latest an activity can finish without delaying project completion.

Formula

LFT = min(LST of Successor Activities)

Importance

  • Helps identify critical activities.
  • Supports project monitoring.

Example 1 (Business)

A project manager calculates LFT for procurement activities.

Example 2 (Practical)

A student determines the latest completion date for data collection.

Topic 7: Slack and Float

Explanation

Slack and Float indicate the amount of time an activity can be delayed without affecting project completion.

Slack

Difference between latest and earliest event times.

Formula

Slack = LFT - EFT

Float

Difference between latest and earliest activity times.

Formula

Float = LST - EST

Importance

  • Identifies scheduling flexibility.
  • Helps prioritize activities.

Example 1 (Business)

A project manager delays a non-critical task because it has available float.

Example 2 (Practical)

A student postpones proofreading because extra time is available before submission.

Topic 8: Critical Path

Explanation

The Critical Path is the longest path through the network.

Activities on the critical path have:

  • Zero Slack
  • Zero Float

Any delay in these activities delays the entire project.

Critical Path Process

↓
Backward Pass

↓

Importance

  • Determines project duration.
  • Highlights critical activities.
  • Supports project control.

Example 1 (Business)

A construction company monitors critical activities daily to avoid delays.

Example 2 (Practical)

A student identifies essential project tasks that must be completed on time.

Topic 9: Probability of Project Completion (PERT)

Explanation

PERT uses three time estimates:

Optimistic Time (To)

Best possible duration.

Most Likely Time (Tm)

Most expected duration.

Pessimistic Time (Tp)

Worst possible duration.

Expected Time Formula

Te = (To + 4Tm + Tp) / 6

Variance Formula

Variance = ((Tp - To) / 6)²

Importance

  • Handles uncertainty.
  • Estimates project completion probability.

Example 1 (Business)

A pharmaceutical firm estimates project completion for drug development.

Example 2 (Practical)

A student estimates completion time for a research project.

Part B: Sequencing Problems

Topic 10: Introduction to Sequencing

Explanation

Sequencing determines the order in which jobs should be processed on machines.

The objective is to minimize total processing time and idle time.

Applications

  • Manufacturing
  • Service Operations
  • Scheduling Systems
  • Project Management

Example 1 (Business)

A factory schedules production jobs to minimize machine idle time.

Example 2 (Practical)

A hospital schedules diagnostic tests efficiently.

Topic 11: n Jobs – 2 Machines Problem

Explanation

This problem involves processing multiple jobs through two machines in a fixed order.

Johnson's Rule

  1. Identify the smallest processing time.
  2. If it belongs to Machine 1, schedule the job first.
  3. If it belongs to Machine 2, schedule the job last.
  4. Repeat until all jobs are assigned.

Flowchart

Find Smallest Time
↓
Machine 1 → Earliest Position
OR
Machine 2 → Latest Position
↓
Repeat
↓
Final Sequence

Example 1 (Business)

A manufacturing unit schedules production jobs through cutting and assembly machines.

Example 2 (Practical)

A printing shop sequences jobs through printing and binding processes.

Topic 12: n Jobs – 3 Machines Problem

Explanation

Three-machine sequencing problems can often be reduced to two-machine problems under certain conditions.

Conditions

The minimum processing time on the first machine must be greater than or equal to the maximum processing time on the second machine, or vice versa.

Example 1 (Business)

A factory schedules jobs through cutting, drilling, and polishing machines.

Example 2 (Practical)

A publishing company sequences editing, formatting, and printing activities.

Topic 13: n Jobs – m Machines Problem

Explanation

This is a generalized sequencing problem involving multiple jobs and multiple machines.

Objectives

  • Minimize total elapsed time.
  • Reduce machine idle time.
  • Improve resource utilization.

Example 1 (Business)

An automobile manufacturer schedules production across multiple workstations.

Example 2 (Practical)

A hospital schedules patients through registration, diagnosis, testing, and treatment stages.

Topic 14: Comparison of Priority Sequencing Rules

Explanation

Priority rules determine the order in which jobs are processed.

Common Rules

FCFS (First Come First Serve)

Jobs processed in arrival order.

SPT (Shortest Processing Time)

Shortest job processed first.

EDD (Earliest Due Date)

Job with earliest deadline processed first.

CR (Critical Ratio)

Priority based on urgency.

Comparison

Rule Main Objective
FCFS Fairness
SPT Minimize Waiting Time
EDD Meet Deadlines
CR Manage Urgency

Example 1 (Business)

Manufacturing firms use SPT to reduce average completion time.

Example 2 (Practical)

Hospitals use priority rules for patient scheduling.

Quick Revision Summary

  • PERT and CPM are project management techniques.
  • PERT uses probabilistic time estimates; CPM uses deterministic estimates.
  • Network diagrams represent project activities and relationships.
  • EST, EFT, LST, and LFT help schedule activities.
  • Slack and Float indicate scheduling flexibility.
  • Critical Path determines project duration.
  • PERT calculates project completion probabilities.
  • Sequencing problems optimize job order on machines.
  • Johnson's Rule solves n-job, 2-machine sequencing problems.
